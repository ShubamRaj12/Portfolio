Methodology & Notes

  1. Schema, data, and original queries are the author's own work, built for an ITC 6000 database design project at Northeastern University. This page embeds the real .db file exactly as submitted.
  2. The dataset is a small, hand-built instructional dataset (6 individuals, 6 food banks, 12 inventory records) designed to exercise the schema — not a live production feed.
  3. Queries are lightly refined from the original coursework versions: a column-alias mismatch, a case-sensitive string match, and a join condition were each cleaned up so every query returns correct, real results here.
  4. The console runs SQLite compiled to WebAssembly (sql.js) entirely client-side — there is no server and no data leaves your browser.
